# gaga

A personal tool, written by LLM and reviewed by its owner.

## Workflow
- Write the files directly, without asking for approval of each change.
- Never commit before being told "commit". No `Co-Authored-By` line in commits.
- Run `cargo +nightly fmt`, `cargo clippy --all-targets` and `cargo test` before handing over.

## Principles
- A single Rust binary. The shell code, generated by `gaga init`, must stay as small as possible: logic goes in Rust.
- zsh and bash are supported, with the same behavior.
- What can be a command of the configuration (`defaults/default-config.toml`) isn't coded in Rust.
- The `enter` hook runs on every `cd`: it must be fast and silent on failure.
- No noise: no needless feature, option, dependency, or comment. Comments are short and say what the code does.
- `README.md` and `CHANGELOG.md` are updated with the change they describe.
